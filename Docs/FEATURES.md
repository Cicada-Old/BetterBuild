# 功能说明

[English](FEATURES.en.md) · RimWorld 1.7 · 更好的建造 1.0.0

本页按「玩家会碰到的界面」讲功能与边界。实现细节见 [架构说明](ARCHITECTURE.md)，已知问题见 [已知问题](KNOWN_ISSUES.md)。

## 1. 建造权限：按小人允许「有品质 / 无品质」

- 每个小人可以分别允许或禁止两类自动建造：**有品质要求**的建筑、**无品质**的建筑。
- 默认全开。
- 你手动右键指派小人建造时，任何人都能接——权限管的是「自动接活」。

用途：让手工低的小人只做无品质的墙和地板，避免他们把带品质要求的家具做成低品质。

## 2. 建造等级范围：每种类型一个区间

- 每种建造类型可设一个建造等级区间，用双柄区间条设定，范围 `0~20`。
- `0~20` 表示**不限制**。
- 只有等级落在区间内、且具备对应权限（见第 1 节）的小人才会自动建造该类型。

## 3. 执行名单：只让指定的小人做某一类

- 每种类型可以指定一份执行名单。名单为空 = 不限制；非空 = 只有名单内的小人能干这类活。
- 名单与等级范围是**两层独立过滤**，必须同时满足。
- 界面状态行会显示「名单 N 人 · 可建造 M 人」，`M = 0` 且名单非空时用警示色。
- **左栏与右区的小人列表各自可排序**（默认 / 等级↑ / 等级↓），两栏互不影响；按建造技能挑人时很方便。

## 4. 建造顺序：拖动 `≡` 决定先做哪一类

- 建造页按类型合并成行，同类蓝图与框架合成一行显示数量。
- 拖动左侧 `≡` 改变顺序，顺序决定调度名次。
- 名次影响两件事：**材料优先给谁**、**谁先被放行**。
- 高名次类型缺料时，材料会为它预留；低名次类型不会抢同类材料；条件不满足的订单自动跳过，不会卡住队列。
- 「跳转」按钮把镜头定位到该类订单所在位置。
- 同类未建造数量达到 5 个时，跳转位置显示「过多」并提示先处理一部分——镜头不会被几百个同类订单反复拖走。

## 5. 材料预算：按名次分配，保护期后开放借用

- 每种材料先满足**最高名次类型**的剩余需求，剩下的额度按（名次，订单）顺序分给低名次订单。
- **一张订单必须拿到它需要的全部材料额度才会被放行**，缺一种就等。
- 最高名次那一组内部**自由竞争**，组内每个订单各自按需取材料。
- **材料保护期**：最高名次占着的材料，保护一段时间（默认 1 游戏日，可调 0~30）之后，**开放一半**给低名次借用。设为 `0` 等于**完全不保护**：低名次按名次顺序直接借，不必等任何一个窗口跑满——这和「到期后开放一半」不是同一回事。
- 预算是软约束：不占游戏预约、不扣库存，只决定「送料任务要不要生成」。
- 改动保护期后，**最迟 15 tick（1 倍速约 0.25 秒）生效**，不是立刻。

## 6. 等待老化：久等的订单自动提权

- 一张订单连续一段时间没有进料（默认 1 游戏日，可调 0~30，`0` 关闭），它的调度名次会被提到**最高名次之后一位**，越过后面所有队列。
- 提权对「让路闸门」和「材料预算」**同时生效**。
- 老化期改动在**下一次注册表刷新**（约 60 tick 内）生效。

用途：队列很长时，队尾的低优先级类型不会永远轮不到。

## 7. 诊断页：逐单说明「为什么不动」

每条订单给出一个结论，共五种：

| 结论 | 含义 |
|---|---|
| **放行** | 材料额度已给，允许执行 |
| **等料** | 预算没给额度；展开可看缺口材料的算式（需求 / 可用 / 库存 / 在途 / 保护 / 已分配） |
| **让路** | 存在名次更高、且他能做的订单，本单先让开 |
| **无人可做** | 权限、等级、名单三层把全部殖民者都挡住了 |
| **禁建** | 玩家在游戏里禁用了这张蓝图或框架 |

补充口径：

- 「等料」里区分**永缺**（库存里确实不够）与**暂缺**（这一时被别的订单占着）。
- 让路发生时，原因列会短暂显示「让给 <类型>（名次 N）」，之后恢复为常规原因（时长见 [已知问题](KNOWN_ISSUES.md)）。
- 结论由不同判定源给出（预算 / 让路闸门 / 无人可做 / 玩家），界面据来源决定这条信息有多「权威」。
- 顶部「执行者视角」可以切成某个小人，显示「<小人> 现在最该做：<类型>（名次 N）」——用来看某个人此刻被派去哪一类活。

## 8. 行高：适配不同分辨率与字号

- 在「调度设置」里按像素设定类型组表格的行高，默认 24，范围 **22~64**。
- 行高同时影响**建造页与诊断页**（诊断页的字体档位与行矩形由它推），左侧小人列表高度固定。
- 超出范围的值会被夹到边界；非数字输入不生效。

## 9. 搜索：按名称过滤

- 窗口右上角有搜索框，输入后**建造页与诊断页同时按名称过滤**：只留下名称匹配的类型组。
- 建造页匹配的是「品质前缀 + 类型名」（例如「[有品质] 木墙」），诊断页匹配的是同一套组名。
- 清空搜索框即恢复全部；表格里的数字始终是全量数据的数字。

## 10. 拆前先拆屋顶

- 拆除会引发屋顶坍塌的承重建筑前，先把普通屋顶清掉。
- **厚岩顶直接拦下不拆**。
- 拆除任务被取消后，会撤销之前打上的屋顶标记，不留残留标记。

## 11. 与 QualityBuilder 的配合

- 手动或自动拆除「已设品质」要求的建筑后，如果 QualityBuilder 没有重新放置蓝图，本模组**兜底补放蓝图并继承品质要求**。
- 这是兼容性行为：装了 QualityBuilder 时，优先由它重放，它没放成时本模组补上。
